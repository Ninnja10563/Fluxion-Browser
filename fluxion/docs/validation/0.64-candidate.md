## Development record

This candidate hardens manual release discovery with a maintained, expiring
public feed. It does not install updates or change 0.63's shipped binaries.

The producer verifies complete release pagination, native tag identity, full
anonymous public DMG/checksum bytes and postflight metadata stability. Its
publication workflow passed on source `114998f7c7336f0e281d20f5cb93e750613463a4`
in [34597299803](https://github.com/Ninnja10563/Fluxion-Browser/actions/runs/34597299803),
bootstrapping feed commit `3b90726a5179619c56aaf5fcdd8a12325a977a6b` for the
already-public 0.63 release. A real anonymous fetch retrieved that feed.

The browser now accepts only the fixed public feed, bounded to 64 KiB and ten
seconds, with full schema/freshness validation and no API fallback. Checks remain
explicit, anonymous and shared across windows. Expired metadata cannot produce
a current-browser claim or retain an earlier download action.

Local combined checks pass all 828 tests, including a Settings regression
checking stale evidence/download cleanup and actionable expired-feed feedback.
Before staging, native validation remained required. The updated gate independently hashes
actual public release bytes before launching, strips maintainer tokens from
the browser environment, and requires real feed HTTP 200 plus exact agreement
with independently discovered release/source/asset metadata. It does not inject
fixture data into the browser response or authenticate its request.

A publishable DMG still requires all native gates, architecture/signature checks,
packaging, archive integrity inspection and independent public-byte verification.
Those requirements are resolved by the full staging and publication above.
