# 0.66 candidate validation

The initial candidate `a3b6d62cde22d50c00094c1909b7d6742632d496` is under
[full macOS staging](https://github.com/Ninnja10563/Fluxion-Browser/actions/runs/34921371802)
with automatic publication disabled. All 870 local regression tests passed.
The native sidebar/frame and large-session selection/structure gates passed.
The new color gate failed before publication: the address background lookup
used an obsolete ID. Pinned Gecko 155 creates `.urlbar-background` instead.
The same stale selector in product CSS explained an unstyled, clashing address
surface in the actual captures. Both product CSS and the verifier now target
the class, with the legacy ID retained only for ESR compatibility. Native
field text/background tokens are explicitly aligned with Fluxion's palette.
No package from the failed run is published.

The Settings accessibility gate also expected a single row title for every
input. The new composite palettes correctly expose distinct names for each
mode, base/accent and picker/hex field. The verifier now checks all eight exact
names and the shared descriptions, instead of expecting four indistinguishable
"Light colors" controls. A local regression checks those same associations.

The new sidebar tests execute the shipped toggle, hover, key and pointer
handlers. They cover focus evacuation before inert, canceled hide timers,
keyboard-vs-pointer ownership, open native menus and stale reveal callbacks.
The existing menu and shortcut fixtures were updated with the controller's
new surrounding state; their actual action/focus assertions remain intact.

Moving tabs and New tab into one scroll region also required moving the
1,000-tab native selection verifier's scroll baseline to that region. Explicit
nonzero baseline assertions prevent a non-scrolling tree from silently passing
the scroll-preservation checks at zero.

Native frame checks now require three routed hover cycles, a pointer-selected
row that subsequently auto-hides, Compact → Expanded and Collapsed → hover →
Expanded, fixed page geometry, reachable inline New tab after overflow, and a
twelve-workspace Compact dock in a short window. The separate color gate
checks actual Settings changes, native address/toolbar colors, cross-window
reset, persisted palettes after clean restart and unchanged static HTTPS page
pixels/document identity. OS color-picker, physical mouse and fullscreen
interaction are not claimed by these synthetic/automated gates.
