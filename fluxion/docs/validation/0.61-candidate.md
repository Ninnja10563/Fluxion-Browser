Final source must pass the full suite, every mandatory native gate, actual
anonymous About HTTP 200, signature/architecture checks and real packaging.
Publication must use that exact artifact, with independent public checksum
verification. No release claim is made until those gates pass.

A subsequent read-only upstream audit found a missing native cold-candidate
boundary: a new excluded URL could be embedded before the final update-complete
cleanup notification. A later batch failure or interruption could retain the
derived vector. Custom retrieval and enriched-store checks already filter the
URL, but those are not a substitute for preventing native indexing. This
pre-existing path is being fixed before full 0.61 staging/publication, with
new cold-candidate, hash-collision and in-flight-policy-change checks.

The feature groups domains supplied by the user; it is not an automatic site
category classifier. Policy edits logically delete matching enriched evidence
and scrub native vectors while retaining Places history, not forensically
erase storage media. Old previews do not understand canonical list policy;
Memory/page AI must be disabled before downgrading a migrated profile.
