# 0.70.1 candidate audit

The release requires one complete successful macOS run at its tagged source.
Individual passing gates below do not substitute for that acceptance run.
Final publication identities belong in the release provenance.

## Corrections found during verification

- **Signed bundle versions.** The DMG guard originally expected the display
  version in `CFBundleVersion`. Updater previews instead need the exact native
  `0.70.1b1` mapping and the full `FluxionReleaseVersion` marker. Packaging now
  checks all three identities and rejects missing/mismatched new-format data.
  Run [35071854083](https://github.com/Ninnja10563/Fluxion-Browser/actions/runs/35071854083)
  then exposed a macOS system-Bash parsing issue in the added heredoc comment.
  Its apostrophe was removed and a system-shell syntax regression added. No
  architecture or signature check was removed.
- **Native migration input.** Run
  [35072088040](https://github.com/Ninnja10563/Fluxion-Browser/actions/runs/35072088040)
  passed wizard cancellation but found the second wizard's selector closed
  before file selection. The verifier had treated missing view state as loaded
  and had no stable paint/geometry barrier before its real pointer activation.
  It now requires a loaded, focused, painted, hit-testable selector with three
  stable geometry samples, then an actually opened native popup and visible
  file-import choice. Subsequent runs passed real NSOpenPanel import, including
  Unicode titles/folders and preservation of an existing bookmark. The original
  failure lacked popup/resize events, so its precise cause is **not proven**.
  New bounded diagnostics record those events; there is no forced popup or
  mocked import fallback.
- **Selected-document restoration.** That same run restored all three saved
  session URLs but immediately compared them with a still-blank selected
  content browser. The fixture now passively waits for the exact three URLs,
  saved selection and matching live selected URI, with a bounded timeout and
  initial/final native-state diagnostics. Permanent blank/wrong selection and
  duplicate tabs still fail. Run
  [35073288552](https://github.com/Ninnja10563/Fluxion-Browser/actions/runs/35073288552)
  directly captured natural `about:blank` to saved-page convergence after 106ms
  on fresh restore and 90ms after full Quit. No navigation, selection, flush or
  save is injected by that readiness check.
- **Security-panel preparation.** Run 35073288552 also showed its first native
  Escape already restored a valid HTTPS proxy and visible identity icon; the
  verifier's unconditional second Escape made it invalid again. Preparation
  now observes state before requesting a second real keypress. Both one- and
  two-Escape paths are regression-tested; run
  [35074101093](https://github.com/Ninnja10563/Fluxion-Browser/actions/runs/35074101093)
  exercised the genuinely needed two-Escape path and opened the correctly
  anchored native security panel. Valid proxy, painted/hit-testable identity,
  native pointer input, security controls and warning meanings remain required.
  This does not resolve the separate initial programmatic Settings-to-page
  address-state behavior noted in the 0.70 audit.
- **Continuous-wheel cadence.** Run 35074101093 requested a 25ms inter-event
  pause which actually lasted 231.04875ms, beyond the shipped 220ms idle
  threshold. Exact event replay reproduced its extra workspace switch. The
  continuous native-wheel fixture now uses a bounded burst without inter-event
  timers and asserts the recorded cadence. All 13 trusted/canceled events,
  one-switch ownership, unchanged page history, four-workspace traversal and
  separate delayed/new-gesture checks remain. Browser thresholds did not
  change. The DOM controller still uses a heuristic rather than physical
  macOS gesture-phase detection; no physical-trackpad conclusion follows.

Earlier native installer verification also corrected two evidence-readiness
issues: comparison before cached fixture URLs arrived, and an HTTP fixture
which recorded a completely consumed tiny XML feed as unfinished when the
client closed immediately. Feed responses now end atomically; a raw-TCP
immediate-close regression exercises that case. The real installer still must
complete all six feed/archive transfers and reject both incorrect-signature
and corrupt archives before its successful replacement/relaunch case.

## Acceptance limits

Installer evidence uses signed isolated fixture versions, not an upgrade of the
published 0.70 binary or a production-DMG installation on the user's M3. It
proves observer-canceled native Quit and retry, not physical interaction with
an unsaved-page prompt. The fixture uses the default profile and restore-session
startup. Private exclusion and fresh-start opt-outs have separate native gates.

The preview is ad-hoc signed, not Apple-notarized. Physical M3/trackpad checks,
native invalid-feed rejection, read-only/interrupted-install recovery and broader
assistive-technology checks remain outside this evidence. No website-speed or
recovery-of-the-user's-original-profile claim is made.
