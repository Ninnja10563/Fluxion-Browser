# 0.65 candidate validation

## Failures used to improve the candidate

The first full macOS staging run,
[34916794555](https://github.com/Ninnja10563/Fluxion-Browser/actions/runs/34916794555),
tested `125a45eea19f86ad9b9a7121b685a32f906fca83`. Ordinary native Command-W
removed the closed Flow row and Command-Shift-T restored it. The new
pointer-close continuation gate failed before its second keyboard command;
the responsive Settings gate also failed its exact 320px root-width wait.
No package from this failed run was published.

Diagnostic run
[34917184211](https://github.com/Ninnja10563/Fluxion-Browser/actions/runs/34917184211),
on `9686f60aa6859eccd295e187da69a432bbcf088b`, recorded the pointer failure's
native event sequence: a trusted mouse click with `detail: 1`, followed about
3ms later by a window blur while `Services.focus.activeWindow` still referred
to the same browser window. There was no pointer leave or scroll. The old
unconditional blur handler released the safety space and moved the neighboring
row from y=220 to y=187. This was a product focus-boundary bug, not a fabricated
test event or an assertion to remove.

The correction waits for native focus bookkeeping and releases the captured
guard only on actual window deactivation. Extracted production-function tests
cover retained same-window focus, actual deactivation, and obsolete callbacks.

Settings accessible names/descriptions passed before the geometry failure.
Its fixture's window-size calculation still assumed no outer content inset;
the new two four-pixel margins left a 312px Settings root when it requested
320px. The fixture now measures actual window-minus-page overhead. The exact
320/600px assertions and clipping/accessibility checks remain unchanged.

## Visual review

Actual first-candidate macOS captures were compared with published 0.64.
Removing redundant header/caption rows reclaimed approximately 59px above the
first tab group. The thin frame and page-owned Settings navigation separated
controls from content without adding a decorative card. Label-sized action
buttons removed repetitive full-width bars.

That review caught a truncated default workspace name; explicit compact
workspace-button padding corrects it. A second review replaced the newly
visible compact toggle's old dot with a sidebar glyph and next-action label,
and synchronized workspace arrow navigation/ARIA orientation with each mode.

## Release candidate

Full staging
[34917639153](https://github.com/Ninnja10563/Fluxion-Browser/actions/runs/34917639153)
tests `00a549a4cb73127b2e8e1ec3bb24afd9ff4e161e`, with automatic publication
disabled. All 844 tests passed. The native keyboard/frame gate passed with
exactly two trusted Command-W events and one Command-Shift-T; the mouse-close
neighbor remained at y=220 through same-window blur. All three sidebar modes,
Settings and Library had four-pixel insets. Actual light/dark HTTPS pages and
a two-page native split were captured and inspected. Settings passed exact
320/600px roots, all ten sections and 200 interactive controls.

This run was not published: the shortcut verifier still queried the old sidebar
button name, and the structural gate encountered an unexpected load count
before any structural operations. The shortcut fixture now locates the real
workspace-band button and checks both new accessible names. The structural
fixture now records its actual baseline count and bounded request evidence
before its unchanged exact-four assertion; no count or live-state protection
was relaxed. The initial artifact did not record the count, so its deeper
cause cannot be inferred from that run.

The screenshot also showed that equal-width workspace buttons still truncated
“Focus.” Content-sized flex bases now allow short default names to use their
natural width; the native gate explicitly checks these labels for clipping.
Final full staging
[34918214921](https://github.com/Ninnja10563/Fluxion-Browser/actions/runs/34918214921)
on `86f54f8c6cf3d1f5f5440275a0ae1c66afe14cb8` passed all 846 tests and every
mandatory native gate, followed by actual DMG packaging. Default labels fit
in all inspected captures. Thirty structural operations passed; exactly four
initial `/transfer` requests were all document navigations, with no additional
loads through seven live-state checks. The earlier count failure did not
reproduce; its unknown cause has not been retrospectively invented.

The exact staged artifact was published as 0.65 after digest, file-count and
checksum verification. Independent public downloads and the release-event
update-feed publication also passed. See
[complete provenance](../../release/provenance/v0.65.0-preview.1.md).

The predecessor run 34917553822 was canceled before completion to include a
final iterable-collection normalization in the exact tested source; it is not
release evidence. Native gates must not be bypassed to publish this milestone.

The reference supplied for this pass is 125 × 84 pixels. Exact visual matching
requires the original image. Physical M3 performance, OS mouse gestures,
fullscreen visual auditing and broader screen-reader coverage remain outside
these automated checks; Apple Developer ID signing/notarization remain open.
