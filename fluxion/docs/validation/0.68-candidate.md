# 0.68 candidate validation

The milestone adds native workspace-heading options, centered dock symbols,
workspace color editing/projection, bidirectional swipe recognition and short
sidebar-only transitions. It retains the original native release gates.

Local regression coverage exercises shipped menu handlers and focus lifecycle,
live workspace entries and stale-command rejection, theme validation and
independent persistence, panel Save/Cancel/Reset and concurrent edits, redundant
color-work avoidance, gesture reversal/axis/momentum behavior, and animation
cancellation/reduced motion. The native product gate adds routed hover/click,
actual macOS Escape/ArrowDown and hex typing, real popup bounds, dock centering,
saved workspace colors and switch-away/back restoration. The native gesture
gate tests rapid reversals and deliberate renewed input after decayed tails.

All 933 local tests passed at source
`d48a7ec4a8206acd0df46213ffc152a6da6b02aa`. The first full native candidate is
[34950133196](https://github.com/Ninnja10563/Fluxion-Browser/actions/runs/34950133196),
with automatic publication disabled. All 933 tests and every mandatory native
gate completed, including architecture/signature checks and DMG packaging.
The new native behavior checks passed:
heading labels stayed fixed through six hover/focus/menu states, actual symbol
centers matched the sidebar midpoint at one/two workspaces, theme data persisted
and restored with Save/Cancel/Reset isolation, and both URL widths kept 6px insets.

This candidate is not published. Actual screenshots revealed a native Cocoa
menu mismatch masked by literal `checked="false"`/`disabled="false"` attributes:
unchecked/enabled items looked checked/disabled. The next candidate removes
false boolean attributes and adds real keyboard radio activation plus recursive
attribute-presence checks. Its theme panel also switches to Gecko's actual
panel tokens, removes duplicate insets and restores the select disclosure arrow.

The address-popup backdrop symptom is intermittent across widths: this run's
wide popup included the app while the narrow popup omitted it. It is not fixed
or confined to one width. The new heading/menu/editor captures included the app.
The user's added custom-Settings request is included in the next candidate.
No physical M3 trackpad, OS color-picker dialog or high-refresh-rate guarantee
is claimed. The first wide address-popup capture limitation from 0.67 remains
explicit and has not been classified as a hardware defect or a harmless capture
artifact. User reference screenshots are not included in the repository.

## Second candidate

Source `faa761e2375e75eb80cb7ed868e69916d44fce44`, run
[34951629590](https://github.com/Ninnja10563/Fluxion-Browser/actions/runs/34951629590),
passed all 945 regression tests. Native product verification and actual image
review confirmed corrected Cocoa checkmarks/enabled states, keyboard workspace
activation, centered symbols, stable hover geometry, and the theme panel's
matching opaque surface and visible dropdown arrow. Both address-popup captures
included the browser this time; intermittent capture behavior is not declared
resolved.

This candidate is also unpublished. The new Settings gate verified all six
live preference changes but failed its immediate `prefs.js` snapshot assertion
for HTTPS-Only Mode. The disk-persistence check must succeed before promotion;
the later release gates and packaging were therefore not completed.

Inspection of Gecko's preference service confirmed that `savePrefFile(null)`
queues/coalesces asynchronous writes. The corrected verifier polls disk within
its existing deadline and requires all six exact preference lines in one
snapshot, together with matching live user values. It does not make product
writes synchronous. Regression cases reject partial snapshots, wrong values,
commented-out entries and disk errors, and exercise delayed completion.

## Final native staging

The unchanged-source full rerun
[34954475634](https://github.com/Ninnja10563/Fluxion-Browser/actions/runs/34954475634)
passed all 951 tests and every mandatory native gate. Only automatic release
publication was skipped; universal architecture/signature verification, DMG
packaging and artifact upload succeeded. The four-load setup requirement stayed
unchanged: exactly four initial documents, all 30 structural operations, zero
unrelated mutations and all seven live-state checks retaining four loads passed.
In the 1,000-tab selection fixture, 30 selections produced zero untouched-row
writes, unchanged-attribute writes or structural row changes; event-to-frame
p50/p95/max were 18.97/20.97/28.86ms. These are CI fixture measurements, not a
physical-M3 refresh-rate or website-loading-speed guarantee.

The actual final product/frame screenshots were reviewed: native checkmarks
and enabled states, theme editor, centered dock, equal address insets, flat
expanded sidebar and rounded/outlined hover overlay were retained. Settings
again required two disk reads for the complete six-preference snapshot;
new-window restoration, scoped resets and policy locks passed. Existing native
transfers/file dialogs, session/crash recovery, private isolation, Memory,
credential, accessibility and update-discovery gates passed. The intermittent
address-popup capture and extra initial document-request observations remain
unresolved limitations; a passing rerun is not evidence of their root cause.

The final artifact was promoted to the public 0.68 prerelease after its raw ZIP,
DMG, checksum, source tag and draft asset digests were verified. Independent
anonymous downloads matched all public bytes, and the verified update feed now
