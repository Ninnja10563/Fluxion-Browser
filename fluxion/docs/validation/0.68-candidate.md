# 0.68 candidate validation

The milestone adds native workspace-heading options, centered dock symbols,
workspace color editing/projection, bidirectional swipe recognition and short
sidebar-only transitions. It retains the original native release gates.

Local regression coverage exercises shipped menu handlers and focus lifecycle,
live workspace entries and stale-command rejection, theme validation and
independent persistence, panel Save/Cancel/Reset and concurrent edits, redundant
color-work avoidance, gesture reversal/axis/momentum behavior, and animation
cancellation/reduced motion. The native product gate adds routed hover/click,
actual macOS Escape/ArrowDown and hex typing, real popup bounds, dock centering,
saved workspace colors and switch-away/back restoration. The native gesture
gate tests rapid reversals and deliberate renewed input after decayed tails.

This candidate is not published. Actual screenshots revealed a native Cocoa

The address-popup backdrop symptom is intermittent across widths: this run's

or confined to one width. The new heading/menu/editor captures included the app.
The user's added custom-Settings request is included in the next candidate.
No physical M3 trackpad, OS color-picker dialog or high-refresh-rate guarantee
is claimed. The first wide address-popup capture limitation from 0.67 remains
explicit and has not been classified as a hardware defect or a harmless capture
artifact. User reference screenshots are not included in the repository.

## Second candidate

Source `faa761e2375e75eb80cb7ed868e69916d44fce44`, run
[34951629590](https://github.com/Ninnja10563/Fluxion-Browser/actions/runs/34951629590),
passed all 945 regression tests. Native product verification and actual image
review confirmed corrected Cocoa checkmarks/enabled states, keyboard workspace
activation, centered symbols, stable hover geometry, and the theme panel's
matching opaque surface and visible dropdown arrow. Both address-popup captures
included the browser this time; intermittent capture behavior is not declared
resolved.

This candidate is also unpublished. The new Settings gate verified all six
live preference changes but failed its immediate `prefs.js` snapshot assertion
for HTTPS-Only Mode. The disk-persistence check must succeed before promotion;
the later release gates and packaging were therefore not completed.

Inspection of Gecko's preference service confirmed that `savePrefFile(null)`
queues/coalesces asynchronous writes. The corrected verifier polls disk within
its existing deadline and requires all six exact preference lines in one
snapshot, together with matching live user values. It does not make product
writes synchronous. Regression cases reject partial snapshots, wrong values,
commented-out entries and disk errors, and exercise delayed completion.
