This records an unreleased candidate, not release provenance. No 0.54 DMG was
published, and no required check was bypassed.

Source `3459f0bdee0d14c019fbdecafea099f2fe606a13` on
`release/0.54-preview` adds a focused correction: choosing a stacked split
retains its orientation through command-palette dismissal. Its 557 regression
tests and native stacked-picker check passed in
[run 34515354934](https://github.com/Ninnja10563/Fluxion-Browser/actions/runs/34515354934).

independent native gates passed. Logs did not capture an exception establishing
the precise cause. Inspection found an unchecked custom-element `getButton`
call during dialog initialization; readiness and exception reporting are being
corrected without removing any success or cancellation assertion. This run
is not eligible for promotion.

## Verified native behavior

- Cross-window adoption retained actual loaded documents, unsaved Unicode text,
  JavaScript state, native back/forward entries, pins, containers, workspace
  membership, collapsed colored groups, and stacked split pairs. Moving did not
  recreate URLs or add spurious source closed-tab records.
- Normal/private boundary crossings and temporary Peek moves were refused;
  same-private-window adoption retained its private identity.
- New-window detachment retained the live page without an extra blank tab.
- The shipped Flow context-menu command and native Gecko DataTransfer DOM
  routing moved actual pages. These checks are not physical OS drag/menu input.
- Moving the last visible tab retained its source window and a real hidden
  page in another workspace, including that page's unsaved text and JavaScript
  state. Gecko's last-tab rule excludes hidden tabs, so the adapter now ensures
  a visible source tab before adoption.
- The session gate adopted grouped/split/pinned-container pages before its
  checkpoint, then verified unique window ownership, container identity,
  shared group identity/color/collapse, workspaces, and stacked split state
  after both clean relaunch and real SIGKILL recovery.
- All existing browser, architecture/signature, Flow, shortcut, bookmark,
  Library, semantic Memory, privacy, accessibility, external link/file, AI,
  authentication, download/upload, and actual macOS file-picker gates passed.

The isolated transfer report is preserved as artifact `10166422580`, named
`Fluxion-0.54.0-preview.1-tab-transfer-evidence`. It is diagnostic evidence,
not an application artifact.

The same run's dark Settings/Flow, light Library, and About screenshots were
inspected. About visibly shows the actual quota error. These diagnostic
screenshots do not make the failed run eligible for release promotion.

## Release check and retry boundary

The About check made one real GET with no cookies, authorization, or referrer,
and no asset requests. GitHub returned HTTP 403 with quota remaining 0 and reset
time **2026-09-10 18:31:51 UTC** (`1789065111`). The UI displayed the error and
retry time honestly. A new live check must wait until that server deadline.

This run was dispatched after the previous deadline, 18:07:42 UTC. A handled
quota error is not accepted as a successful release-discovery check. Publication
still requires a complete successful staging run and independent verification
of its exact artifact, checksum, and public release bytes.

## Failures corrected before this candidate

Earlier diagnostic runs exposed real integration issues and fixture mistakes:

- `34509137474`: the history fixture used Gecko's default user-interaction
  filtering to traverse programmatic, unactivated pushState entries. The fixture
  now explicitly traverses those entries; ordinary Back/Forward is unchanged.
- `34509842282`: menu validation relied on legacy node ownership rather than
  current Gecko's `documentGlobal` interface.
- `34510397619`: detachment retained an untouched startup placeholder. The
  destination now explicitly opens blank and cleanup preserves changed pages,
  typed address drafts, and unknown history/document state.
- `34511382590`: principal validation called an unavailable security-manager
  method. It now reads Gecko's native principal accessor with a strict boolean
  check; tab membership and privacy validation remain required.
- `34511797735`: live adoption/menu/drag checks passed, but the new recovery
  fixture lost its otherwise-empty source window before checkpointing. Its
  retained pages now exist before transfer, and the production last-visible-tab
  bug was independently fixed and verified with a real hidden workspace page.

No failed or diagnostic-only application was promoted.
