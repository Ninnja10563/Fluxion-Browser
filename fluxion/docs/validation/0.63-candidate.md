# Fluxion 0.63 candidate validation

This unpublished candidate adds whole-group drag reordering around ordinary
tabs, groups and splits, and intact split-pair drops into groups. Its keyboard
menu equivalent now moves around all top-level units, not just other groups.

The source uses current native-object membership and validates whole split
units before mutation. Foreign, closed, pinned and cross-workspace members are
rejected; web text cannot manufacture a privileged drag session. Drop-time
validation is separate from hover feedback, and cleanup runs on failed native
operations as well as successful drops.

Initial integrated checks passed 781 tests; the added runtime-handler and actor
registration tests brought that to 789. Two further tests check the live-state
verifier rejects document changes and reloads. The final combined suite passes
all 791 tests, with syntax checks and no failures or skips.
The expanded native structure gate requires 30 operations, with actual Flow
drag handlers and Gecko DataTransfer. It checks native placement, membership,
collapse/orientation, global visible order and retained controls. Synthetic
chrome events are not physical OS drag/trackpad evidence.

Four real loopback pages are seeded with unique document nonces, unsaved form
text, JavaScript counters and navigation state. The native gate must preserve
all of these through six group moves and the split-to-group drop, with exactly
four server document loads throughout. The existing fixed-command actor is
registered only under explicit verification flags and exact loopback origin;
normal browsing does not register it. Its companion transfer verifier is
explicitly disabled for this structure run.

Final integrated tests and actual macOS diagnostics remain required. A public
DMG also requires full staging, all mandatory native gates, real anonymous
About HTTP 200, signature/architecture checks, packaging and exact-artifact
verification. 0.62 remains the latest public release.
