# 0.69 candidate validation

Local and native gates cover repeated four-workspace gestures, Focus-mode
top-edge navigation, inset sidebar surfaces, native address/security-panel
focus, matching New tab hover geometry, stationary-pointer tail closure,
multi-page workspace appearance previews and persistence, and background
indexing timer reuse. Publication requires a complete passing native run and
inspection of the actual screenshots; no candidate has been promoted yet.

Local preflight passes 994 tests with no failures, skips or cancellations.
The guarded session archive repack was also checked against the locked official
Gecko archive: all 5,353 entries retain their ordering and all CRCs pass, with
only the two intended SessionStore/SessionSaver members changed. Neither result
establishes native macOS UI, shortcut delivery or last-window behavior.

## First native candidate

[35037871415](https://github.com/Ninnja10563/Fluxion-Browser/actions/runs/35037871415)
built source `8f000c8b4539b8fe2506d6a6f265475ac62212b3`. The app built and passed
signature/architecture checks, but four native gates failed; no DMG was packaged
or published. All other mandatory gates passed.

- Frame: the identity fixture selected a now-hidden legacy control instead of
  Gecko 155's visible trust control. Screenshot review also exposed a product
  bug not covered by the old assertion: the address field's native top layer
  remained painted after its ancestor toolbox hid. The follow-up suppresses
  the actual field only while hidden and independently checks paint/hit testing.
- Shortcuts: real Cocoa Command+Option input arrived at the focused recorder,
  but Gecko also sets AltGraph for Option. The policy rejected those events.
  The follow-up accepts that specific macOS modifier combination while retaining
  non-macOS AltGr, text composition, Control and reserved-binding protections.
- Existing recovery: the seed fixture awaited seven companion-window pages,
  but not two primary-window pages. One remained about:blank at its assertion.
  Readiness now requires all nine exact tab/URL pairs and completed loads;
  expected restoration is unchanged. A rerun must prove this, not assume a flake.
- Last-window: the new fixture parsed an already-structured Gecko state object,
  failing before it exercised the patch. It now uses the pinned native return
  type. No last-window behavior was established by this failed run.

Actual product screenshots revealed a Firefox-colored bookmarks stripe. The
follow-up projects the workspace frame palette onto that native toolbar and
adds computed-color assertions. The two-page appearance editor otherwise passed
native Save/Cancel/Reset and global-page-scheme isolation checks. Both address
popup screenshots retained their main-window backdrop in this attempt, without
establishing that the previously intermittent omission is fixed.

The native gesture gate passed a four-workspace route in both directions,
vertical scrolling and unchanged page-history checks. Physical gestures remain
outside that routed-input evidence.

The project owner's subsequently supplied icon PNGs are imported unchanged;
their native ICNS packaging and updated UI need the next complete candidate.
The follow-up local preflight passes all 1,003 tests, including icon import,
native-size generation failure paths, Cocoa modifier handling, and stronger
session-fixture readiness. No failures, skips or cancellations were reported.

## Second native candidate

[35038868836](https://github.com/Ninnja10563/Fluxion-Browser/actions/runs/35038868836)
built source `0711c5727c2a753c459ecc4a91f01f25e1fccb9a`. All 1,003 local tests,
the native icon/signature/architecture checks, frame, shortcuts, and existing
full session/private/crash-recovery gates passed. No DMG was packaged or
published: product, structural setup, and last-window gates failed.

Actual screenshots now show the supplied app icon in the Dock, no address
field left behind in hidden Focus, a six-pixel floating sidebar, and a revealed
native toolbar/trust panel without content reflow. New tab retained its actual
218px width and 28/34/36px density heights on hover. The stationary-pointer
trailing close settled in 126.8ms with surviving tabs preserved; this is a CI
interaction measurement, not a physical-M3 performance guarantee.

Trusted macOS key evidence confirmed Command+Option+Shift+K arrived with both
Alt and AltGraph, was saved, and activated the actual sidebar action. Reserved
Command-W was rejected without closing Settings. Cross-window persistence,
Reset, Escape, blur and live preference checks passed.

- The new product color assertion selected transparent `#fluxion-flow`, not
  its painted `.fluxion-surface`. The helper is corrected and has a regression
  that accepts the transparent layout container but rejects mismatched painted
  chrome. Real light/dark frame captures show the bookmarks stripe is corrected.
- Structural setup repeated the earlier unproven extra request: its second
  initial page navigation made two document requests, giving five instead of
  four. Seeding made none, one window existed, and no structural operations had
  run. The strict four-document gate remains. Bounded setup-only native channel
  and server lifecycle diagnostics are being added to distinguish causes.
- Last-window restoration passed its first actual close/reopen with three
  unique URLs, pinned state and custom metadata. Its second close then lacked
  the expected normal-page recovery record. The cause is not established;
  pre/post-flush and closed-record diagnostics are needed before changing
  policy. The rapid second close and recovery assertions are retained.

The newer native trust panel still contains Firefox-branded status text and
artwork. This is not a disposable promo: the same section includes disabled,
insecure and breach states. It was left intact rather than hiding security
information. A future scoped localization/artwork change must preserve all
warning meanings, controls and state selection.

Known prior limitations remain explicit: physical M3 trackpad and OS color
picker dialogs have not been audited; earlier address-popup captures sometimes
omitted the browser backdrop; one earlier large-session fixture had an extra
initial document request of unproven cause. The strict document-load gate is
retained. User reference screenshots are not copied into the repository.
