# Fluxion 0.62 candidate validation

The latest public DMG is 0.61. This unpublished candidate extends Flow's keyed
updates to groups and splits instead of rebuilding every sidebar row whenever
those structures change.

Tab and control identity survives group-level changes and split wrapping.
Group headings retain unique accessible child-container IDs. Split wrappers
are projection-local; collapsed groups continue showing only the active page.
The whole tree plan is validated, new parents are connected first, and obsolete
containers are pruned only after surviving descendants are reparented. Focus
recovery respects external controls, and pointer-close holding still defers
structural work. Native object identity prevents restored objects with reused
IDs from inheriting stale event handlers.

All 763 local tests and syntax checks passed before the final native-verifier
extension. That extension uses Firefox 155's documented native
`group.addTabs([splitWrapper])` path and real split reversal, not fabricated
group/split objects. Final integrated local and macOS diagnostics remain required.

The final integrated candidate, including that native verifier and the updated
health-marker contract, also passes all 763 local tests and syntax checks.

Successful diagnostics alone cannot publish a DMG: full release staging must
also pass all browser gates, the actual anonymous About request, signature and
architecture checks, real packaging, and exact-artifact/public-checksum
verification. No physical-hardware frame-rate claim is made.
