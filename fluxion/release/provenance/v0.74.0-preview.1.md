## Limits

Universal macOS 12+ preview, ad-hoc signed and not Apple-notarized. No website
speed benchmark or physical M3/trackpad improvement is claimed. The original
roadmap is not complete. Accent changes apply to Fluxion's controls and focus
indicators, not webpage controls or macOS dialogs; low-contrast colors are
adjusted for visibility.

## Rejected candidates

Run [35325414905](https://github.com/Ninnja10563/Fluxion-Browser/actions/runs/35325414905),
source `ac295d9ea401e3b71415d3931ecc5cfdb1132015`, passed 1,247 local checks
and built the universal application, but failed native gates. It was canceled
after preserving the new-gate evidence, and no artifact was published.

- The existing toolbar-menu fixture still required New Tab to allocate a tab
  immediately. Its check was updated to require a focused draft, unchanged
  source and unchanged tab count on supported Gecko, while retaining the old
  native fallback check on unsupported controllers.
- New Tab received real Cmd-T twice without creating tabs, then failed while
  awaiting the address query. The fixture's replacement-promise tracker could
  retain a predecessor rejection. Tracking now binds both outcomes to the
  exact current promise; genuine current-query failures still fail and include
  their original error. This is not proof that the first rejection was benign.
- The same-path branding fixture reproduced stale native About/Hide/Quit
  Firefox labels with Fluxion resources. Browser-window labels were Fluxion;
  the hidden window retained Firefox. Artifact `10538893724` preserves actual
  native-menu captures and the resource/DOM/Accessibility reports. Repair
  capture failed because the launcher's canonical `/private/var` path differed
  from the fixture's `/var` alias. The fixture now canonicalizes its own root
  before constructing app/profile paths, retaining exact process ownership and
  the strict stale-menu assertion.

The next candidate also includes the user's checkbox-accent fix. It scopes
Gecko's accent-aware checkbox renderer to Fluxion Settings outside forced-color
mode, without custom checkmark drawing or webpage/OS-dialog styling.

Run [35326117902](https://github.com/Ninnja10563/Fluxion-Browser/actions/runs/35326117902),

Its New Tab gate still failed: artifact `10539208871` identified Gecko's
`SearchEngine.searchUrlPublicSuffix` rejecting the test search engine's IP

example hostname mapped to loopback only in its isolated profile, verifies the

all content; the chrome-only `-moz-theme` cannot be inspected that way. The
replacement check retains actual checked/enabled state, appearance, projected
accent color and hit testing, with native screenshots reviewed separately.
This is not a claim that a computed color alone proves pixel rendering.
