## Limits

Discovery reads profile metadata, not browsing databases, and requires a
separate confirmed transfer. Zen/Firefox imports use the latest saved bookmark
backup; recent edits may be absent and repeated imports can add duplicates.
Passwords, cookies, signed-in sessions, workspace layouts and extensions are
not copied by that feature. Manual import options remain available.

No whole-browser speed, physical M3/trackpad, battery, storage or prolonged-use
stability improvement is claimed. This is an ad-hoc-signed development preview,
not Apple-notarized or a completed assistive-technology/stability certification.
