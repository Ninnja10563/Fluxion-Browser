## Distribution limits

This universal Apple Silicon/Intel preview is ad-hoc signed, not Developer-ID
signed or Apple-notarized. Existing 0.70 and older installations require one
manual DMG upgrade to obtain the native updater. Initial native installation
supports the default profile, one running application process, and an app
outside the mounted DMG. Unsupported arrangements retain manual installation.
Keep Startup set to restore the previous session when tab restoration is
wanted; fresh-start choices remain respected.

Physical M3/trackpad checks, an actual unsaved-page Quit dialog, native
invalid-feed rejection, read-only/interrupted-install recovery and broader
assistive-technology audits remain outside this evidence. No website-speed
improvement is claimed. 0.71 remains the measured performance milestone; the
original roadmap is not complete.
