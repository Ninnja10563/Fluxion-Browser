## Performance boundary

Normal direct startup loads fall from 105 to 74 (32 test-only scripts removed,
one production empty-workspace controller added). Disabled Memory avoids
indexing activity hooks; hidden Library and subframe events avoid redundant
DOM work. Tests execute real controllers, including cross-window preference
changes, stale asynchronous completions and privacy cleanup.

No physical M3 or Speedometer improvement has been measured. The reported
34.4 ± 2.4 baseline needs the same benchmark version, machine, profile and power
conditions for comparison. The Mozilla runtime already uses native optimized
PGO/LTO builds. Security and process isolation were not weakened. The complete
original roadmap and a reviewed Gecko 156 upgrade remain outstanding.
