## Limits

The reported loading delay remains unisolated. Module-startup diagnostics are
not total-launch or browsing benchmarks; no M3 Speedometer, memory, battery or
whole-browser speed gain is claimed. The 72-case CSS sidebar fixture is not
native Gecko. Physical M3/trackpad and broader assistive-technology audits remain
outstanding. This is an ad-hoc-signed development preview, not Apple-notarized.
See the [milestone](../../docs/milestone-0.77.md) for feature scope and import limits.
