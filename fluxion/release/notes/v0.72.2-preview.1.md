# Fluxion 0.72.2 — Native branding details

- The Extensions popup uses Fluxion's transparent F instead of Firefox's fox
  illustration. Native extension controls and permissions are unchanged.
- Adds verification of the actual macOS application-menu labels and native
  Extensions popup, alongside the existing packaged branding checks.
- Retains 0.72.1's directional hover navigation, edge-to-edge hidden-sidebar
  content and final-workspace-tab focus fix.

Universal macOS 12+ preview for Apple Silicon and Intel. Use Update and restart
on supported installations, or quit Fluxion and replace Fluxion.app using the
DMG. Ad-hoc signed, not Apple-notarized. See the
[milestone](https://github.com/Ninnja10563/Fluxion-Browser/blob/main/fluxion/docs/milestone-0.72.2.md)
for verification scope and limitations.
