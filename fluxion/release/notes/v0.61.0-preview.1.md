# Fluxion 0.61 — Local Memory controls

Universal macOS preview for Apple Silicon (including M3) and Intel. Gecko is
included; a separate Firefox installation is not required.

- Create named collections of excluded domains, enable or disable each list,
  and keep direct exclusions separate. Matching includes subdomains.
- Preserve unsaved Settings drafts across windows and reject conflicting edits
  instead of silently overwriting newer changes.
- Stop native indexing of newly visited excluded pages before their content
  reaches the local embedding model. This addresses the indexing limitation
  disclosed after 0.60 was published.
- Keep malformed exclusion policies closed to indexing and recall without
  treating corruption as permission to erase existing data. Recovery and
  explicit deletion remain separate actions.
- Refine the compact list editor's checkbox alignment and domain-count copy,
  with real macOS screenshots and keyboard/accessibility checks at narrow widths.

All 746 regression tests and every required native macOS release gate passed,
including actual local-model retrieval, excluded cold-page inputs, cross-window
cleanup, private isolation, restart/crash recovery, real browsing and dialogs,
1,000-tab checks, anonymous update discovery and DMG packaging. The DMG is the
unchanged artifact from that exact tested build.

Browser Memory remains optional and local; ordinary browsing works with it
disabled. Lists contain domains supplied by you, not automatic site categories.
Deletion is logical cleanup, not forensic erasure. Previously allowed in-flight
work is drained before an exclusion save reports successful cleanup; a crash
during that operation is not an atomic-erasure guarantee. Older previews do not
understand list policies: disable Memory and page AI before downgrading.

Open the DMG and drag Fluxion.app into Applications. This is an ad-hoc-signed
development prerelease, not Apple-notarized or a completed stable product.
