# Fluxion 0.64 — Reliable release discovery

Universal macOS preview for Apple Silicon (including M3) and Intel. Gecko is
included; a separate Firefox installation is not required.

- About now checks a small, verified public release feed instead of depending
  on GitHub's anonymous repository API quota.
- Checks remain manual, anonymous and shared across windows. No browsing data,
  credentials, cookies or installed-version query is sent. Checking does not
  download an app or checksum; download and installation require your action.
- Expired or malformed feed data produces an actionable error, never a false
  current-version claim or a retained download button from an earlier check.
- The maintainer feed publisher verifies actual public DMG/checksum bytes,
  release/source identities and hashes before updating metadata. Refreshes are
  serialized and cannot force-overwrite the feed branch.

All 828 regression tests and every native macOS release gate passed. The real
browser received public feed HTTP 200, made no GitHub repository API request,
and matched independently verified release/source/asset evidence. Maintainer
verification tokens were absent from the browser process. Existing browsing,
tab, workspace, session/crash recovery, privacy and local Memory checks passed.

This is release discovery, not a signed automatic updater. Public hosting can
still fail or briefly cache older data; feed expiry prevents indefinite reuse.
Published 0.63 and earlier retain their old update-check implementation until
you install this preview. Normal browsing remains independent of AI.

Open the DMG and drag Fluxion.app into Applications. This is an ad-hoc-signed
development prerelease, not Apple-notarized or a completed stable product.
