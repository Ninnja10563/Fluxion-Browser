# Fluxion 0.66 — sidebar and appearance

A universal macOS preview for Apple Silicon (including M3) and Intel, using
Firefox/Gecko. No Chromium-based components.

- Collapse leaves a hover-reveal edge; Expand keeps the sidebar open. Compact
  remains an explicit Appearance option instead of another hidden toggle step.
- New tab sits directly below the final tab. Recognizable workspace symbols
  stay in the bottom dock, which remains usable with twelve workspaces in a
  short window.
- Custom light/dark base and accent colors are available in Settings →
  Appearance, with native pickers, hex fields, readable text and Reset.
- Address-bar surfaces use the correct Gecko styling hooks. Settings
  dropdowns have visible native disclosure arrows.
- Command-W row synchronization, native browser services and private-data
  protections are retained.

Quit Fluxion, open the DMG, and replace Fluxion.app in Applications. Existing
Fluxion profiles are retained. The app includes Gecko; Firefox does not need
to be installed separately.

This is an ad-hoc-signed development preview, not Apple-notarized. Physical
M3/trackpad and broader assistive-technology audits remain; the complete
original roadmap is not finished. See the repository's milestone and release
provenance for exact validation evidence.
