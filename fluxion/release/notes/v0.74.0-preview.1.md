# Fluxion 0.74 — Address-bar drafts and cleaner chrome

- New Tab opens the address bar first. Submit an address or search to create
  the tab, or cancel without adding an empty tab.
- Workspace headings align beside bookmarks, immediately below navigation.
- Removes the blue focus line left along the page when the sidebar is hidden,
  while preserving keyboard focus feedback on the revealed sidebar.
- Workspace highlight colors now apply to Fluxion Settings checkboxes, with
  a clearer picker label and preserved high-contrast behavior.
- Refreshes Gecko's chrome cache after a changed Fluxion build, without
  clearing tabs, history, bookmarks or other browsing data. Subsequent warm
  launches retain the cache.

Universal macOS 12+ preview for Apple Silicon and Intel. Use **Update and
restart** on supported installations, or quit Fluxion and replace Fluxion.app
using the DMG. Ad-hoc signed, not Apple-notarized. See the
[milestone](https://github.com/Ninnja10563/Fluxion-Browser/blob/main/fluxion/docs/milestone-0.74.md)
for verification scope and limitations.
