# Fluxion 0.77 — Workspace folders and browser imports

Universal macOS development preview for Apple Silicon and Intel, powered by
Firefox/Gecko. No Chromium-based components.

- Create folders from the workspace heading's right-click or three-dot menu.
  Folders sit above the divider, can remain empty, and preserve their names
  and collapsed state with the window's session. Move to Folder and dragging
  into an empty folder keep the existing tabs and account containers intact.
- Settings → Import data accepts bookmark HTML and password CSV/TSV exports
  from Zen or Firefox, opens Chrome's native migration dialog, and can add up
  to 100 pasted web-tab links that load only when selected. This does not clone
  profiles, extensions, workspace layouts or signed-in sessions. Password
  exports contain readable passwords; keep them private and remove them after use.
- Fullscreen Focus navigation overlays the page rather than moving its content
  down and back up. The hover region follows the toolbar's actual height, and
  hidden macOS window controls no longer reserve an empty left-side gutter.
- About Fluxion can copy local module-startup timings for troubleshooting.
  No browsing history or profile paths are included, and nothing is sent
  automatically. The reported loading delay remains under investigation;
  no Speedometer or total-launch-time improvement is claimed.

Quit Fluxion, open the DMG, and replace Fluxion.app in Applications. Existing
profiles are retained. The app includes Gecko; Firefox need not be installed.
Updater-enabled installations can use the explicit Update and restart action
once the verified update channel offers this version.

This preview is ad-hoc signed, not Apple-notarized. Physical M3/trackpad and
broader assistive-technology audits remain outside the automated checks.
