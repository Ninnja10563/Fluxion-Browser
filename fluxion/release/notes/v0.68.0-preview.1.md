# Fluxion 0.68 — workspace details

A universal macOS preview for Apple Silicon (including M3) and Intel, using
Firefox/Gecko with no Chromium.

- Hover the workspace heading to reveal its three-dot options button and a
  subtle highlight. Keyboard focus reveals the same control, without shifting
  the heading or tabs.
- Rename, change icon/accent, switch workspaces, reorder, create and safely
  delete from the native menu. Workspace entries come from your saved spaces.
- Edit Workspace Theme provides a color picker and hex field for separate
  light/dark colors, with Save, Cancel and Reset. Text stays readable and page
  colors stay unchanged. Workspace symbols are centered in the bottom dock.
- Open-menu highlighting and Escape focus restoration keep the interaction
  connected to its button. Existing workspace data and sessions are preserved.
- Swipe recognition tolerates small diagonal starts and deliberate reversals
  during a previous gesture's tail. Ordinary momentum still cannot skip through
  workspaces; vertical scrolling and webpage input retain their own behavior.
- A 150ms, 4px sidebar-only transition follows workspace changes. Page selection
  is immediate; reduced motion disables the effect and rapid switches replace it.

Quit Fluxion, open the DMG and replace Fluxion.app in Applications. Firefox
does not need to be installed separately.

This preview is ad-hoc signed, not Apple-notarized. The full original roadmap
is not finished. Physical M3 trackpad behavior still needs hardware validation.
The first wide address-popup screenshot limitation documented in 0.67 is not
claimed fixed: please report any first-Command-L window flash or disappearance.
