# Fluxion 0.59 — Browser Memory Privacy

Universal macOS preview for Apple Silicon (including M3) and Intel. Gecko is
included; a separate Firefox installation is not required.

- Close encoded-sensitive-path bypasses in Browser Memory's exclusion policy.
- Remove matching old saved page text and vectors on ordinary startup, even
  when Memory is disabled, while retaining ordinary browsing history.
- Preserve safe neighboring evidence and apply the same policy to retrieval.
- Prepare exclusion rules once per cleanup batch to avoid repeated work.
- Reject exclusion lists above 200 distinct domains without silently dropping
  entries or reporting a partial save as successful.

All 668 regression tests and every native macOS release check passed, including
real browsing, native dialogs, private isolation, clean/crash recovery and
disabled-Memory startup cleanup. The DMG is promoted from that tested build.

Sensitive-page detection is heuristic, not a guarantee that every sensitive
page is recognized. Database deletion is logical, not forensic media erasure.
Category-based exclusions remain unfinished.

Open the DMG and drag Fluxion.app into Applications. This is an ad-hoc-signed
development prerelease, not Apple-notarized or a completed stable product.
