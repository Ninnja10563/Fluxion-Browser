# Fluxion 0.76 — Refined sidebar and lighter background work

The workspace heading now stays above scrolling tabs. Clicking its title or
symbol opens workspace options. Tabs, folders and New Tab share consistent
spacing, and New Tab reveals its keyboard shortcut on hover or keyboard focus.
Subtle feedback respects reduced-motion preferences.

Background tab scans skip ineligible tabs before asynchronous work, search
ranking retains bounded candidate lists, and Browser Memory loads its embedding
module only when needed. Packaged branding artwork uses lossless compression.
Component benchmarks improved locally; no Speedometer or whole-browser speed
increase is claimed without a matching Mac benchmark.

The launcher recreates a deleted Fluxion profile directory on the next launch,
and reports inaccessible paths without replacing existing files or other
profiles. This creates a fresh profile; it cannot recover deleted browsing data.

All 1,338 regression tests and mandatory native macOS gates passed, including
session recovery, sidebar/fullscreen layout, branding and signed update/restart.

Install the universal DMG by replacing Fluxion.app in Applications, or use
Update and restart in an updater-enabled version. Apple Silicon and Intel are
supported. Existing profiles are retained; Firefox need not be installed.

This is an ad-hoc-signed development preview, not Apple-notarized. See the
repository's 0.76 milestone and release provenance for verification evidence
and remaining performance-validation limits.
