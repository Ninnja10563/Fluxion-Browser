# Fluxion 0.69 — Focus and workspace appearance

A universal macOS preview for Apple Silicon (including M3) and Intel, built on
Firefox/Gecko with no Chromium.

- Focus mode hides the sidebar completely; edge hover reveals an inset floating
  surface without corner fragments. The navigation bar appears at the top edge
  and remains available for keyboard address entry and native security panels.
- New tab highlights like an ordinary row. Closing the trailing tab promptly
  compresses its space; middle-row accidental-repeat-close protection remains.
- Gentle repeated swipes can continue through more than two workspaces, with
  existing direction, momentum and reduced-motion safeguards.
- Workspace Appearance combines actual light/dark/system appearance and base/
  accent editing into one multi-page panel with previews, Save and Cancel.
- Background indexing reuses its pending wake during activity bursts instead
  of continually resetting timers, while still waiting for a quiet period.
- Fresh profiles restore sessions and show the bookmarks bar by default;
  explicit existing choices remain unchanged.
- Shortcut recording takes keyboard focus after a macOS click and cancels
  cleanly when leaving Settings. Command+Option bindings recognize native
  macOS modifier flags, including the default workspace shortcuts.
- Updated app, About and new-tab icons use the supplied Fluxion artwork.

Quit Fluxion, open the DMG and replace Fluxion.app in Applications. Gecko is
included. This is an ad-hoc-signed preview, not Apple-notarized. The original
roadmap is unfinished and physical M3/trackpad checks remain. See the candidate
audit for native evidence and unresolved observations.
