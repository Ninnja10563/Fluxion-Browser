# Fluxion 0.78 — Smoother sidebar and reliable menu-bar hover

Universal macOS development preview for Apple Silicon and Intel, powered by
Firefox/Gecko. No Chromium-based components.

- Moving upward into the macOS menu bar keeps Focus navigation visible,
  including native fullscreen menu-bar animation. Moving back down into the
  page retracts it; expanded and compact sidebars retain persistent navigation.
- Sidebar layout changes settle the page column once rather than repeatedly
  resizing webpages and Settings during a width animation. The floating
  sidebar retains its short slide, with matching fade timing and no animated
  shadow repaint. Its hide grace period now matches the toolbar's 60ms.
- Rapid sidebar hide/reopen cancels obsolete keyboard-focus requests. Switching
  modes clears stale keyboard ownership, and already-hidden or persistent
  sidebars do not schedule unnecessary hide timers.
- The command palette now respects Fluxion's Interface motion switch. Folder
  disclosure also respects macOS Reduce Motion.
- Includes the redesigned drag-to-install DMG, workspace folders, and browser
  import tools introduced in 0.77.

Quit Fluxion, open the DMG, and replace Fluxion.app in Applications. Existing
profiles are retained. Updater-enabled installations can use Update and restart
once the verified update channel offers this version.

This is an ad-hoc-signed development preview, not Apple-notarized. Automated
checks do not establish physical trackpad/M3 performance or exhaustive
screen-reader coverage. No Speedometer or whole-browser speed increase is
claimed; the changes target chrome layout work and interaction correctness.
