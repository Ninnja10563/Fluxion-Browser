# Fluxion 0.73 — Careful tab cleanup

- Right-click a tab and choose **Close Duplicate Tabs…** to review duplicates
  in the current workspace. Only exact web addresses in the same account
  container match; query strings and fragments are not discarded.
- Selected, right-clicked, pinned, grouped, split, Peek and active-media tabs
  are protected. Cancel is the default confirmation action. Native unsaved-page
  prompts and Reopen Closed Tab remain available.
- Fixes canceled Peek closure forgetting the preview's source tab. A retained
  preview can still be kept or opened beside its source, without a second
  close prompt caused by nested selection events.

Universal macOS 12+ preview for Apple Silicon and Intel. Use **Update and
restart** on supported installations, or quit Fluxion and replace Fluxion.app
using the DMG. Ad-hoc signed, not Apple-notarized. This is a tab-management
improvement, not a claim of faster website benchmarks. See the
[milestone](https://github.com/Ninnja10563/Fluxion-Browser/blob/main/fluxion/docs/milestone-0.73.md)
for verification scope and limitations.
