# Fluxion 0.72 — Sidebar alignment and quicker Focus navigation

- The expanded sidebar heading moves up too, reserving only the real macOS
  window-button row. Narrow windows retain a safe navigation fallback.
- Animated Focus navigation uses a shorter 120 ms retract and 60 ms departure grace.
  Pointer reentry, typing, security popups and reduced motion remain protected.
- Copy one tab link or several selected tab links from the sidebar's native
  context menu without switching pages. URL authority credentials are omitted.
- Retains 0.71's tab-management optimizations and existing session fixes.

Universal macOS 12+ preview for Apple Silicon and Intel, powered by Gecko.
Use Update and restart on supported 0.70.1+ installations, or quit Fluxion and
replace Fluxion.app in Applications using the DMG. Profiles are retained.
This preview is ad-hoc signed, not Apple-notarized.

See the [milestone](https://github.com/Ninnja10563/Fluxion-Browser/blob/main/fluxion/docs/milestone-0.72.md)
for implementation and verification scope. No website-speed gain is claimed.
