# Fluxion 0.75 — Empty workspaces and less background work

Closing the last tab now leaves an empty workspace and keeps the window open.
Other workspaces remain intact. New Tab or Command-T opens the address field;
a tab appears only after you submit a URL or search. Escape cancels without
leaving a blank tab behind. Pressing Command-W again does not cycle through
invisible replacement tabs or add phantom entries to undo history.

Gecko still supplies the underlying browser, security, search and session
services. Explicitly opened blank pages remain ordinary tabs. Empty backing
pages are excluded from tab search, bookmarks, grouping, splits, container
actions, duplicate cleanup and tab sleeping.

This version also reduces normal startup from 105 to 74 directly loaded scripts,
avoids repeated updates to the hidden Library, and detaches indexing activity
hooks while Browser Memory is disabled. These are reductions in browser work,
not a measured Speedometer or M3 performance gain. Please retest under matching
benchmark, profile and power conditions.

All 1,325 regression tests and mandatory native macOS gates passed, including
last-window recovery, private isolation and signed update/relaunch. Actual
normal/private empty-workspace and address-draft screenshots were reviewed.

Install the universal DMG, or use the updater's Update and restart action in an
updater-enabled version. Apple Silicon (including M3) and Intel are supported.
Profiles are retained; Firefox does not need to be installed separately.

This is an ad-hoc-signed development preview, not Apple-notarized. The complete
original roadmap and physical M3/trackpad audits are not finished. See the
repository's 0.75 milestone and release provenance for validation details.
