# Fluxion 0.67 — quieter chrome, sidebar gestures

A universal macOS preview for Apple Silicon (including M3) and Intel, built on
Gecko without Chromium.

- Navigation and bookmarks align with the page column. The address field has
  balanced vertical spacing, a quiet fill and one focus outline.
- Refined neutral frame, consistent tab spacing, subtle page corners and a
  small menu control. The active workspace appears above its tabs; symbols stay
  in the bottom dock and New tab stays below the final row.
- Swipe horizontally with two fingers over the sidebar to change workspace.
  Vertical scrolling still scrolls tabs; one gesture changes one workspace.
- New profiles start with one workspace. Existing workspaces and sessions stay
  intact.
- Removed the Firefox-only VPN promotion that collided with toolbar controls
  and the "Firefox Suggest" heading. Suggestions use one clean popup frame.
  Native extensions, permissions, site security and developer tools remain.

Quit Fluxion, open the DMG and replace Fluxion.app in Applications. Existing
profiles are retained; Firefox does not need to be installed separately.

This is an ad-hoc-signed preview, not Apple-notarized. Automated macOS geometry
and Gecko-routed input checks do not replace physical M3/trackpad testing.
The full original roadmap is not complete.

Known verification limitation: CI's first 1280px address-popup screenshot omits
the main-window backdrop, although native keyboard, retrieval and geometry
checks pass and the 800px popup capture is complete. A capture/compositing
artifact has not been distinguished from a visible first-open issue. Please
check the first Command-L interaction on your Mac and report any window flash
or disappearance. This preview does not claim that hardware audit is complete.
