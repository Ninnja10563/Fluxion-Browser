# Fluxion 0.71 — Responsiveness with many tabs

- Less background work: sleeping-tab scans no longer repeatedly copy the whole
  tab list, and private windows avoid an unnecessary sleeping timer.
- Workspace selection reads each eligible tab's remembered state once, retaining
  tab order, restoration behavior and malformed-state recovery.
- The command palette reuses unchanged tab-organisation analysis while checking
  live changes and revalidating suggestions before applying them.
- Existing Focus navigation, sidebar layout and native browser services remain.

Universal macOS 12+ preview for Apple Silicon and Intel, using Gecko.
0.70.1 or newer can use Update and restart when offered; older installations
require one manual DMG installation. Quit Fluxion and replace Fluxion.app in
Applications. Profiles are retained. Ad-hoc signed, not Apple-notarized.

See the [milestone](https://github.com/Ninnja10563/Fluxion-Browser/blob/main/fluxion/docs/milestone-0.71.md)
for reproducible comparisons and verification scope. These are browser-chrome
optimizations, not a claim of higher website benchmark scores.
