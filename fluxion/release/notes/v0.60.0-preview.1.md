# Fluxion 0.60 — Steadier Flow

Universal macOS preview for Apple Silicon (including M3) and Intel. Gecko is
included; a separate Firefox installation is not required.

Known privacy limitation found after publication: with Browser Memory enabled,
a newly visited excluded site can receive a native local embedding before
background cleanup. Interrupted processing can leave that vector on disk.
Keep Browser Memory disabled if you rely on exclusions until the fix is
released. Ordinary browsing works without Memory; no external upload was
demonstrated by this audit.

- Keep unaffected sidebar tabs and their controls connected when opening,
  closing, reordering, pinning or unpinning flat tabs in the same workspace.
- Preserve keyboard focus and independent pinned/tab-list navigation entries.
- Move a single reordered row with one DOM relocation; preserve existing
  grouped, split and workspace-switching behavior.
- Validate DMG version metadata against the supplied app so manual packaging
  cannot accidentally relabel an older build.

All 687 regression tests and every required native macOS release gate passed,
including a 1,000-tab structural test, real browsing, native dialogs, private
isolation, clean/crash recovery, actual update discovery and real packaging.
The DMG comes from that exact tested build.

This reduces unnecessary sidebar mutations; it does not virtualize tabs or
establish sustained high-refresh-rate performance on physical hardware.
The separate named Memory exclusion-list candidate is not included.

Open the DMG and drag Fluxion.app into Applications. This is an ad-hoc-signed
development prerelease, not Apple-notarized or a completed stable product.
