# Fluxion 0.72.1 — Predictable Focus navigation

- Moving upward from the toolbar toward the macOS menu bar keeps navigation
  visible. Moving below the toolbar retracts it; address typing and open
  security menus still retain their native focus protections.
- Hidden-sidebar mode removes the page gutter and rounded content frame.
  The sidebar reveal edge overlays the page, and the revealed sidebar stays
  floating. Expanded and compact layouts retain their existing frame.
- Closing the final tab in a workspace skips the unnecessary row-compression
  wait. Its native replacement no longer implicitly selects the address bar
  in Focus mode, which previously could leave hover navigation stuck open.

Universal macOS 12+ preview for Apple Silicon and Intel. Use Update and restart
on supported installations, or quit Fluxion and replace Fluxion.app using the
DMG. This preview is ad-hoc signed, not Apple-notarized. See the
[milestone](https://github.com/Ninnja10563/Fluxion-Browser/blob/main/fluxion/docs/milestone-0.72.1.md)
for verification scope and limitations.
