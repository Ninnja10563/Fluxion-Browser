# Fluxion 0.65 — Clearer tabs, quieter chrome

Universal macOS preview for Apple Silicon (including M3) and Intel. Gecko is
included; a separate Firefox installation is not required.

- Fixes stale Flow rows after Command-W, including closing after a stationary
  mouse close. Reopening closed tabs remains backed by native SessionStore.
- Keeps mouse-close safety spacing when Gecko moves focus into page content,
  while releasing it on real window deactivation or keyboard interaction.
  Canceled page-leave prompts restore surviving rows instead of hiding them.
- Combines workspace controls into one compact band, removes repeated rail
  branding and the redundant Flow caption, and brings tabs higher up.
- Uses a thin, solid content frame, quieter Settings navigation, label-sized
  actions and consistent page/sidebar glyphs. Default workspace labels fit.
- Compact workspace navigation follows Up/Down; the sidebar toggle stays
  visible and names its next action. Expanded workspaces retain Left/Right.

The unslop-ui design audit informed this restraint pass. The supplied reference
was only 125 × 84 pixels; this is not a claim of exact visual matching.

All 846 regression tests and every mandatory native macOS release gate passed,
including actual Command-W/Command-Shift-T, stationary pointer spacing, real
HTTPS pages in light/dark and split view, 1,000-tab structural changes, narrow
Settings, session/crash recovery, private-data exclusion and local Memory.
The real application screenshots were inspected before publication.

Quit Fluxion, open the DMG and replace Fluxion.app in Applications. Your
separate Fluxion profile is retained. This is an ad-hoc-signed development
prerelease, not Apple-notarized or a completed stable product. The full roadmap
and physical-hardware/accessibility audits remain unfinished.
