# Fluxion 0.70.2 — Focus mode follows the sidebar

All 1,136 regression tests and every required native macOS gate passed.

- Hidden sidebar: the top bar retracts after you leave it, including when
  browsing Fluxion Settings or the floating sidebar in macOS fullscreen.
- The floating sidebar starts near the top edge, with its workspace heading
  directly below the small inset instead of reserving space for navigation.
- Expanded and compact sidebars keep the top bar visible. Address typing and
  security popups retain their toolbar until that interaction ends.
- Explicit Focus mode works with older saved fullscreen-autohide settings
  without changing your saved preference.

Universal macOS 12+ preview for Apple Silicon and Intel, using Gecko.
0.70.1 users can use Update and restart when offered; 0.70 or earlier requires
one manual DMG installation. Quit Fluxion and replace Fluxion.app in Applications.
Profiles are retained. This preview is ad-hoc signed, not Apple-notarized.

See the [milestone](https://github.com/Ninnja10563/Fluxion-Browser/blob/main/fluxion/docs/milestone-0.70.2.md)
for verification scope. No website-speed improvement is claimed.
