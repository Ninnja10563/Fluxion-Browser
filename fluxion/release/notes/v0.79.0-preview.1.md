# Fluxion 0.79 — Profile detection and calmer navigation

Universal macOS development preview for Apple Silicon and Intel, powered by
Firefox/Gecko. No Chromium-based components.

- Import settings automatically finds Zen, Firefox and Chrome profiles in
  their usual locations. Discovery checks profile metadata, not passwords or
  browsing history, and does not import anything without a separate action.
- Zen and Firefox can add bookmarks from their latest saved bookmark backup
  without manually locating an export. Existing Fluxion bookmarks are retained.
  Recent edits may be absent from a backup; repeated imports can add duplicates.
  Passwords still use CSV exports, and cookies, signed-in sessions, workspace
  layouts and extensions are not copied by this feature.
- A detected Chrome profile opens the native importer for choosing supported
  data. Manual import/export options remain available if detection fails.
- Hidden-sidebar navigation releases inherited startup focus even when the
  backing page is hidden or not yet focusable. Gecko's speculative focused
  attribute cannot by itself pin the toolbar open. Later Cmd-L/Cmd-T and native
  security prompts retain their keyboard ownership.
- Toolbar retraction now takes 200ms instead of 120ms. The short departure
  grace period, menu-bar retention, reduced motion and persistent navigation
  with an open sidebar are preserved.

Quit Fluxion, open the DMG, and replace Fluxion.app in Applications. Existing
profiles are retained. Update-enabled installations can use Update and restart
after the verified update channel offers this version.

This remains an ad-hoc-signed development preview, not Apple-notarized. It is
not a completed stability or performance certification. Automated checks do
not replace physical-device, prolonged-use or assistive-technology testing.
No whole-browser benchmark improvement is claimed.
