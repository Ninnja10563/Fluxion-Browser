# Fluxion 0.70.1 — Updates and window behavior

**Draft: native verification and release publication are pending.**

Universal Gecko-based macOS preview for Apple Silicon (including M3) and Intel.
Updater-enabled builds require macOS 12 or later; no Chromium components.

- A quiet update icon offers an explicit one-click update and restart. About
  shows progress, available cancel/retry actions and a manual DMG fallback.
- Optional automatic metadata checks run through one shared coordinator while
  normal windows are open. Disable them in Settings → About. They never grant
  permission to download or install an application automatically.
- Sparkle 2.10.0 authenticates the signed update feed and archive. Installation
  requests native, cancellable browser quit before replacement and relaunch.
- Closing the final tab keeps a normal window open with a replacement tab;
  pages in other workspaces remain separate and retained. Window close and Quit
  remain native session operations, not tab-mirroring features.
- Expanded and compact sidebars keep navigation visible, also in macOS
  fullscreen. Hidden/Focus mode retains top-edge reveal, pointer-leave retraction
  and genuine keyboard/security-popup focus.

Upgrade from 0.70 or earlier manually: quit Fluxion, open the DMG and replace
Fluxion.app in Applications. Existing profiles are retained. The initial native
updater supports only the default profile and one running application process,
outside the mounted DMG; unsupported arrangements retain manual installation.

This is an ad-hoc-signed development preview, not Apple-notarized. Native
installation/session/toolbar acceptance is still pending; do not interpret these
draft notes as a passing release report. No website-speed improvement is claimed.
See the [milestone](https://github.com/Ninnja10563/Fluxion-Browser/blob/main/fluxion/docs/milestone-0.70.1.md)
and [update contract](https://github.com/Ninnja10563/Fluxion-Browser/blob/main/fluxion/docs/update-channel.md).
