# Fluxion 0.62 — Stable grouped tabs

Universal macOS preview for Apple Silicon (including M3) and Intel. Gecko is
included; a separate Firefox installation is not required.

- Keep surviving tab rows and their close/audio controls connected when
  grouping, ungrouping, reordering and wrapping tabs in split views.
- Preserve group headings, accessible relationships and owned keyboard focus
  through structural changes, including nested splits and collapsed groups.
- Minimize sidebar moves without rebuilding unaffected rows. This is an
  interaction-stability improvement, not a new visual skin or tab virtualization.

All 770 regression tests and every required native macOS release gate passed.
The real 1,000-tab structure check exercised 21 operations, including grouped
splits, collapse/expansion and separation: zero unaffected row writes and one
relocation for an adjacent swap. Real browsing, private isolation, recovery,
local semantic retrieval, anonymous update discovery, architecture/signature
checks and DMG packaging also passed. The download is the unchanged staged DMG.

Browser Memory remains optional and local. Ordinary browsing works without AI.
Hosted-runner checks do not establish physical M3 frame rates or input latency.
The original roadmap is not complete; whole-group dragging and additional
interaction and accessibility work remain.

Open the DMG and drag Fluxion.app into Applications. This is an ad-hoc-signed
development prerelease, not Apple-notarized or a completed stable product.
