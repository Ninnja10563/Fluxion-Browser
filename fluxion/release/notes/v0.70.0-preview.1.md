# Fluxion 0.70 — Identity and interaction repairs

Universal macOS preview for Apple Silicon (including M3) and Intel, powered by
Gecko. No Chromium-based components.

- Shared browser names identify Fluxion, including quit confirmation.
- Transparent F artwork replaces browser mascots, About and New Tab branding.
- macOS Control shortcuts are distinct from Command shortcuts.
- Closing a tab no longer leaves a gap until the mouse moves.
- Bookmark import uses the real Gecko import wizard outside custom Settings.
- General offers “Make Fluxion Default” and reads the actual OS default-browser
  status. macOS retains control of confirmation.
- Tab right-click menus offer existing Gecko account containers, opening a
  separate page without copying the original account's session data.
- Workspace colour editing has an integrated draggable colour field, keyboard
  ranges and live preview, with Save and Cancel in the same paged menu.
- Closing the final visible workspace tab retains pages in other workspaces.

Focus navigation retracts after explicit sidebar collapse and reveals for
top-edge hover or Command-L. Fullscreen uses native toolbar behavior and
eight-pixel page corners. The unslop-ui review kept controls compact, aligned
and free of extra decorative containers.

All 1,065 regression tests and every mandatory native macOS gate passed in
[the release build](https://github.com/Ninnja10563/Fluxion-Browser/actions/runs/35062000814).
Six last-window stages passed, including normal quit/relaunch, workspace and
pinned-tab retention, private exclusion and startup opt-outs. These are isolated
profile tests; the original reported 0.69 profile and physical red-window-button
behavior have not been independently reproduced.

Quit Fluxion, open the DMG, and replace Fluxion.app in Applications. Existing
profiles are retained. Then choose **Settings → General → Make Fluxion Default**
and confirm with macOS. The app includes Gecko; Firefox is not required.

This preview is ad-hoc signed, not Apple-notarized. Automatic update installation
and automatic workspace-to-container assignment remain pending. A programmatic
Settings-to-page test retained a provisional address state until native Escape
reversion; its cause remains under investigation. See the
[candidate audit](https://github.com/Ninnja10563/Fluxion-Browser/blob/main/fluxion/docs/validation/0.70-candidate.md)
for exact evidence and limits. 0.71 is the next measured performance milestone;
no website benchmark or fastest-browser claim is made here.
